Helse-skjema — klient-side generator

Last opp JSON (skjema-data) og generer en .docx-fil lokalt. Valgfritt: last opp logo (PNG/JPG). Logo settes i header på første side. Sidetall vises i footer.

Hvordan bruke

  1. Last opp JSON-filen (du kan laste opp store filer direkte i nettleseren).
  2. Last opp logo hvis du ønsker (logo vises i topp på første side).
  3. Valgfritt: skriv inn felt-navn som skal være lange fritekstfelt (komma-separert). Hvis tomt brukes heuristisk match mot vanlige navn som inneholder "forespørsel", "merknad", etc.
  4. Klikk "Generer .docx" — filen lastes ned automatisk.

Merk: dette er en klient-side generator (alt skjer i nettleseren). Hvis du foretrekker å kjøre på server kan vi legge til en node-løsning senere.

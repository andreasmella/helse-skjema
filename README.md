# Helse-skjema (klient-side generator)

Denne repoen inneholder en enkel helt klient-side web-app som lar deg laste opp et JSON-objekt med skjema-data og (valgfritt) en logo, og genererer en .docx-fil i brukerens nettleser.

Hurtigoversikt

- Åpne index.html i nettleseren (eller host via GitHub Pages).
- Last opp din JSON-fil (skjemaet).
- Last opp logo (valgfritt).
- Klikk "Generer .docx" — nedlasting starter.

Merk: implementasjonen bruker docx-biblioteket i nettleser. Hvis du ønsker at jeg skal bruke PDF-designet du sendte som referanse for nøyaktig layout, kan jeg iterere etter at du tester denne versjonen.

Enable GitHub Pages

1. Gå til repo -> Settings -> Pages
2. Velg main branch og root (/) som source, lagre.
3. Sidene vil være tilgjengelige som https://andreasmella.github.io/helse-skjema/

Hvis du vil at jeg skal legge til logoen direkte i repo-en, last opp logo.png via repoens upload eller gi meg beskjed så kan jeg pushe den.
